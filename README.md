# Interactive Task Management

Hey there! This is my second coding project for my Web Development Program. I made this cool to-do list that lets you drag tasks between different categories. Pretty neat, right? 😎

## What it does

This app lets you:
- Add tasks to a list
- Drag them between 3 columns (Tasks, Completed, Do Tomorrow)
- Add notes to your tasks when you click the Notes button
- Delete tasks you don't need anymore
- Your tasks stay saved even when you close the browser!

## How I built it

I used:
- HTML (structure)
- CSS (making it look nice)
- JavaScript (making it actually work)

No fancy frameworks or anything, just the basics we learned in class!

## How to use it

1. Download the files (index.html, styles.css, and script.js)
2. Put them in the same folder
3. Open index.html in your browser
4. Start adding tasks!

## Things I learned

- How to use the draggable attribute in HTML
- How localStorage works (so cool that you can save stuff!)
- How to create and style a modal window
- How to make divs look like cards with CSS
- Event listeners in JavaScript
